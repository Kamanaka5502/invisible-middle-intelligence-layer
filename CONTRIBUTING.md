# Contributing

The Invisible Middle Intelligence Layer is a structural systems intelligence project focused on hidden human compensation, burden transfer, containment instability, and flourishing restoration.

## Contribution Principles

Contributions should preserve:

- category integrity
- human dignity
- neurodivergent respect
- non-reductive interpretation
- anti-surveillance posture
- structural interpretation over behavioural blame
- flourishing restoration orientation

## The Core Question

All contributions should remain aligned with the operating question:

> Where is the system asking humans to compensate for missing structure?

## Appropriate Contributions

Examples:

- signal taxonomy improvements
- evidence architecture refinement
- rebalance logic improvements
- report templates
- dashboard surface concepts
- burden/flourishing assessment logic
- workflow examples
- AI burden transfer examples
- contextual interpretation models
- documentation clarity
- runtime improvements
- testing and validation

## Inappropriate Contributions

Examples:

- employee scoring systems
- productivity ranking systems
- punitive behavioural surveillance
- medicalised user reduction
- hidden tracking systems
- coercive optimisation systems
- flattening neurodivergent interaction into defect scoring

## Boundary

This repository is intentionally public-safe.

Protected Elyria / Veritas substrate materials, private scoring law, enforcement runtime logic, and customer deployment infrastructure are not part of the public contribution surface.
