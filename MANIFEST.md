# Repository Manifest

This manifest records the public-safe contents of the Invisible Middle Intelligence Layer repository.

It exists to prevent reduction, accidental omission, and accidental disclosure of protected or commercial material.

## Repository Purpose

The repository contains the public Invisible Middle Intelligence Layer:

> structural systems intelligence for hidden human compensation, burden transfer, containment instability, and flourishing restoration.

Core question:

> Where is the system asking humans to compensate for missing structure?

## Public Boundary

This repository does not contain or claim a live protected Elyria / Veritas enforcement substrate.

Where Elyria Systems / VA is referenced, it refers to organizational framing, public-safe integration boundaries, evidence-envelope compatibility, and optional future runtime handoff surfaces.

## Non-Reduction Standard

The repository is valid only where it makes hidden human compensation more visible without making the human more reducible.
