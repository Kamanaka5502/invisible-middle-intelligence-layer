# Layer Interface Boundary

This note records the working separation between the Invisible Middle Intelligence Layer and protected consequence-boundary infrastructure.

## Separation

The current boundary is:

```text
Invisible Middle = interpretation / structural intelligence
Elyria / VERITA = protected consequence infrastructure
```

## Invisible Middle Authority

The Invisible Middle layer holds interpretation authority.

It identifies, organises, and interprets:

- signal families
- weighting relationships
- cross-domain correlation
- temporal behaviour
- hidden compensation
- burden movement
- trust instability
- closure weakness
- governance ambiguity
- AI burden transfer
- flourishing impact

It defines what is being detected, interpreted, evidenced, and classified.

## Protected Runtime Authority

Elyria / VERITA holds consequence authority where separately licensed and operationally applicable.

That category includes:

- admissibility
- refusal
- binding
- runtime enforcement
- replay
- protected consequence-boundary resolution

This public repository does not expose those internals.

## Interface Shape

The clean interface is:

```text
Invisible Middle identifies and interprets the structural condition.
Evidence envelope preserves what was detected and why.
If consequence-level action is needed, the finding may route downstream into protected runtime boundary infrastructure.
```

## Boundary Rule

The systems may connect.

They should not collapse into each other.

Invisible Middle should not be positioned as the protected runtime substrate.

Elyria / VERITA should not be reduced into a dashboard, diagnostic layer, or ordinary workflow tool.

## Final Position

This separation gives the Invisible Middle layer its own integrity while keeping deeper consequence infrastructure protected.
