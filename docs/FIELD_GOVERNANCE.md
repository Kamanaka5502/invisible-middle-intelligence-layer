# Field Governance

The Invisible Middle Intelligence Layer must remain governed by its origin field.

It is not a neutral analytics package.

It is a structural intelligence layer built to protect the distinction between visible system completion and hidden human compensation.

## Core Governance Rule

The layer may interpret system conditions.

It must not reduce human beings into scores, defects, compliance units, productivity objects, or behavioural risk labels.

## Non-Reduction Boundary

Every implementation must preserve these separations:

```text
human signal ≠ human defect
visible behaviour ≠ diagnosis
completion ≠ support
speed ≠ reduced burden
AI output ≠ human relief
smooth interface ≠ smooth consequence
```

## Origin Integrity

The layer is rooted in neurodivergent detection of unsmooth systems.

That origin is not decorative.

It is part of the intelligence basis.

Neurodivergent and high-sensitivity interaction patterns can reveal system instability earlier because unresolved ambiguity, weak closure, lost context, unclear authority, and repeated interpretive burden land in the human field before formal failure appears.

## Allowed Interpretive Posture

The layer may say:

- the system is shifting burden
- context is fragmenting
- trust is unstable
- closure is weak
- authority has moved without control
- AI is creating hidden afterwork
- participation is degrading
- flourishing is being constrained

The layer should avoid saying:

- this user is the problem
- this behaviour proves defect
- this person is noncompliant
- this group is inefficient
- this worker is risky
- this child is difficult

## Field Preservation Rule

Any dashboard, report, classifier, schema, runtime, or buyer-facing material must preserve the field relationship:

```text
Human Signal Field
+ Burden Field
+ Flourishing Field
+ System Field
+ Movement Field
+ Evidence Field
+ Rebalance Field
```

No single field should be extracted and sold as the whole layer.

## Dashboard Boundary

The dashboard is only a visibility surface.

It must not become:

- surveillance
- performance scoring
- productivity ranking
- user blame
- compliance theatre
- generic workflow analytics

## Runtime Boundary

The public runtime scaffold demonstrates structural interpretation only.

It does not expose protected Elyria / Veritas substrate mathematics, scoring law, kernelization logic, enforcement internals, or live consequence-boundary operation.

## Commercial Boundary

Commercial packaging must preserve ownership and field integrity.

Carla’s Invisible Middle layer remains Carla’s field-facing layer.

Elyria Systems / VA remains the protected runtime/integration frame where licensed.

The combined offer must not blur authorship, ownership, protected boundaries, or origin logic.

## Final Governance Standard

The layer is admissible only where it protects the human field from being flattened.

If an implementation makes people easier to score but not easier to support, it has left the field.
