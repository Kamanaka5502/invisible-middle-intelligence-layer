# Field Coherence Admission Standard

Every future change must preserve the multidimensional field architecture of the Invisible Middle Intelligence Layer.

This standard exists because the layer can be damaged by language, code, dashboards, buyer materials, or examples that make the work easier to package but less true.

## Admission Question

Before committing, ask:

> Does this change preserve the full field relationship?

If the answer is uncertain, do not commit until the field relationship is restored.

## Required Field Preservation

Each meaningful addition should preserve at least one of these fields without contradicting the others:

```text
Human Signal Field
Burden Field
Flourishing Field
System Field
Movement Field
Evidence Field
Rebalance Field
Optional Boundary Field
```

## Inadmissible Collapse Patterns

Reject changes that collapse the layer into:

- dashboard software only
- productivity analytics
- user scoring
- behaviour monitoring
- generic AI governance
- ordinary UX audit
- wellness or wellbeing branding
- accessibility compliance alone
- workflow optimisation language
- enforcement-kernel claims
- protected runtime claims

## Required Protection Lines

Where relevant, preserve these distinctions:

```text
visible completion ≠ reduced burden
human signal ≠ human defect
workflow speed ≠ support
AI output ≠ relief
dashboard surface ≠ intelligence layer
signal visibility ≠ structural interpretation
burden detection ≠ flourishing restoration
```

## Code Standard

Runtime code should remain public-safe and demonstrative.

It may show:

- signal intake
- contextual interpretation
- structural condition classification
- burden mapping
- flourishing assessment
- report generation
- dashboard snapshot structure

It must not expose:

- protected substrate mathematics
- private admissibility machinery
- scoring law
- kernelization logic
- enforcement internals
- live consequence-boundary runtime
- customer law bundles
- private adapters

## Documentation Standard

Documentation should stay:

- clear
- humane
- field-preserving
- buyer-readable where appropriate
- practitioner-usable where appropriate
- technically inspectable where appropriate

It should not become inflated, vague, mystical, punitive, legal-heavy, or generic.

## Final Gate

A change is admissible only if it makes the Invisible Middle clearer without making the human field smaller.
