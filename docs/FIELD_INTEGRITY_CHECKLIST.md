# Field Integrity Checklist

Use this checklist before adding new code, reports, dashboards, buyer materials, examples, or public language.

The purpose is simple:

> Do not make the Invisible Middle visible by making the human reducible.

## 1. Origin Integrity

Before publishing, confirm:

- [ ] The neurodivergent-rooted origin is preserved.
- [ ] The work is not presented as generic workflow analytics.
- [ ] Human strain is treated as system intelligence, not personal defect.
- [ ] NDPP / Invisible Middle framing remains visible where appropriate.

## 2. Field Coherence

Confirm the material preserves the relationship among:

- [ ] Human Signal Field
- [ ] Burden Field
- [ ] Flourishing Field
- [ ] System Field
- [ ] Movement Field
- [ ] Evidence Field
- [ ] Rebalance Field
- [ ] Optional Boundary Field

No single field should be mistaken for the whole layer.

## 3. Anti-Surveillance Check

Reject the change if it creates or encourages:

- [ ] employee scoring
- [ ] behaviour ranking
- [ ] productivity policing
- [ ] hidden monitoring
- [ ] deficit labelling
- [ ] punitive escalation
- [ ] neurodivergent pathologising

## 4. Evidence Discipline

Confirm:

- [ ] Signals are not treated as conclusions.
- [ ] Context is used before interpretation.
- [ ] Evidence strength is visible.
- [ ] Temporal patterns are considered where relevant.
- [ ] Human-reported experience is respected but not exploited.

## 5. Rebalance Discipline

Confirm the output asks:

- [ ] What burden moved?
- [ ] Who is carrying it?
- [ ] What structure is missing?
- [ ] What would restore trust, closure, ownership, predictability, or continuity?
- [ ] Does the system support flourishing, or merely process people faster?

## 6. Boundary Discipline

Confirm the material does not expose or claim:

- [ ] protected Elyria / Veritas substrate mathematics
- [ ] private admissibility machinery
- [ ] scoring law
- [ ] kernelization logic
- [ ] enforcement internals
- [ ] customer law bundles
- [ ] live consequence-boundary runtime

## 7. Final Gate

Before committing, answer:

> Does this make hidden human compensation more visible without making the human more reducible?

If no, do not merge it.
