# Non-Reduction Charter

This project must not reduce the Invisible Middle into ordinary software language.

The layer is not simply a tool, feature, dashboard, classifier, workflow add-on, AI governance component, or accessibility checklist.

It is a field-facing intelligence layer for identifying where systems appear complete while humans are still carrying missing structure.

## Governing Commitment

The Invisible Middle Intelligence Layer must preserve the full field relationship:

```text
Human Signal Field
+ Burden Field
+ Flourishing Field
+ System Field
+ Movement Field
+ Evidence Field
+ Rebalance Field
+ Optional Boundary Field
```

If a description, implementation, buyer pitch, dashboard, schema, or runtime shortcut removes those relationships, it has reduced the layer.

## What Must Never Be Flattened

### Neurodivergent Origin

The neurodivergent origin is not a marketing story.

It is part of the detection logic.

The layer begins from the recognition that neurodivergent and high-sensitivity interaction patterns often reveal unsmooth systems earlier because ambiguity, weak closure, lost context, unclear authority, and repeated interpretive burden land directly in the human field.

### Hidden Human Compensation

The layer must preserve the distinction between visible completion and hidden compensation.

A system can complete the workflow while still requiring humans to carry the real consequence.

### Flourishing

The layer must not become strain-only analytics.

It must also ask whether the system supports agency, participation, confidence, recovery capacity, trust, continuity, autonomy, and sustainable engagement.

### Movement

The layer must track where burden moves.

Burden can transfer, accumulate, rebound, compress, become consequence, or be rebalanced.

### Evidence

The layer must preserve why a structural interpretation was made.

Signals alone are not conclusions.

Interpretation requires context, evidence strength, temporal patterning, and field coherence.

## Forbidden Collapse Patterns

The layer must not collapse into:

- productivity analytics
- user satisfaction research
- ordinary UX review
- employee scoring
- behaviour surveillance
- generic AI monitoring
- wellbeing branding
- accessibility compliance alone
- workflow optimisation theater
- protected-runtime disclosure

## Correct Category

The correct category is:

> structural systems intelligence for hidden human compensation, burden transfer, containment instability, and flourishing restoration.

## Final Rule

The layer is only valid where it makes hidden human compensation more visible without making the human more reducible.
